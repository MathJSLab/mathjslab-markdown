# Álcool e éter: mesma fórmula, ligações diferentes

**Extensões:** `smiles`, `mathjax`.

## Ideias principais

Etanol e dimetil éter têm fórmula $\ce{C2H6O}$, mas conectividades distintas.
Em `CCO`, o oxigênio terminal recebe um hidrogênio implícito; em `COC`, ele
liga os dois carbonos.

```smiles
CCO
```

```smiles
COC
```

## Prática

Qual desenho contém o grupo O–H? A fórmula molecular basta para distinguir as
duas substâncias?

## Resposta comentada

CCO representa o álcool com O–H. A fórmula molecular é igual; a conectividade é
necessária para distingui-los.
