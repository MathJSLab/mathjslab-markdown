# Amônia: geometria piramidal

**Extensões:** `molecule-3d`, `smiles`, `mathjax`.

## Ideias principais

A amônia $\ce{NH3}$ tem três ligações N–H e um par de elétrons não ligante. As
coordenadas XYZ são um modelo ilustrativo de pirâmide trigonal, não uma
medição. A representação SMILES não determina, sozinha, a geometria espacial.

```smiles
N
```

```xyz
4
Modelo ilustrativo de amônia
N 0.000 0.000 0.300
H 0.940 0.000 -0.100
H -0.470 0.814 -0.100
H -0.470 -0.814 -0.100
```

## Prática

Quantos átomos há no modelo? A molécula inteira é plana?

## Resposta comentada

Há quatro átomos. Não: o nitrogênio está fora do plano dos três hidrogênios.
