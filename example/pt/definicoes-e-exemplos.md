# Definições e exemplos: norma de um vetor

**Extensões:** `didactic`, `cross-references`, `mathjax`.

## Ideias principais

Uma definição fixa o significado; um exemplo mostra como usá-la. A {@ref norma}
e o exemplo abaixo distinguem um vetor de seu comprimento.

::: definition Norma euclidiana {#norma}

Para $v=(x,y)$, definimos $\|v\|=\sqrt{x^2+y^2}$.

:::

::: example Vetor (3,4)

$\|(3,4)\|=\sqrt{9+16}=5$.

:::

## Prática

Determine a norma de (-3,4). O sinal negativo torna o comprimento negativo?

## Resposta comentada

A norma vale 5; os quadrados das componentes são não negativos.
