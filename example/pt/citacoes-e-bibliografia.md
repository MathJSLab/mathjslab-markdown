# Citações e bibliografia

**Extensões:** `citations`.

## Ideias principais

As notas de Ada Lovelace [@lovelace1843] e o trabalho de Turing [@turing1936]
oferecem duas perspectivas históricas. Podemos citar as fontes juntas
[@lovelace1843; @turing1936]. Os dados ficam no documento, sem consultas
externas.

```bibtex
@article{lovelace1843,
  author={Lovelace, Ada},
  title={Notes on the Analytical Engine},
  journal={Scientific Memoirs},
  year={1843},
  volume={3}
}
```

## Prática

Troque `apa` por `vancouver` e inverta a ordem das primeiras citações. O que
muda?

## Resposta comentada

O estilo numérico usa números conforme a ordem da primeira citação. Atualizar a
ordem atualiza a bibliografia.
