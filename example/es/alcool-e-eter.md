# Alcohol y éter: misma fórmula, enlaces diferentes

**Extensiones:** `smiles`, `mathjax`.

## Ideas principales

El etanol y el dimetil éter comparten la fórmula $\ce{C2H6O}$, pero tienen
conectividades distintas. En `CCO`, el oxígeno terminal recibe un hidrógeno
implícito; en `COC`, conecta los dos carbonos.

```smiles
CCO
```

```smiles
COC
```

## Práctica

¿Qué dibujo contiene el grupo O–H? ¿La fórmula molecular basta para distinguir
las sustancias?

## Respuesta comentada

CCO representa el alcohol con O–H. La fórmula molecular es idéntica; se
necesita la conectividad para distinguirlos.
