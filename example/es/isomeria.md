# Isomería: misma fórmula, estructuras diferentes

**Objetivo:** distinguir la isomería de cadena y de función. **Extensiones:**
SMILES y MathJax.

## La fórmula no es un mapa de enlaces

Los compuestos de fórmula $\ce{C4H10}$ pueden tener una cadena lineal o
ramificada. Compara el butano y el 2-metilpropano:

```smiles
CCCC
```

```smiles
CC(C)C
```

Ambos tienen cuatro carbonos y diez hidrógenos, pero la conectividad es
diferente. Este caso se clasifica como isomería de cadena.

## Isomería de función

El etanol y el metoximetano comparten la fórmula $\ce{C2H6O}$. El primero
contiene un grupo hidroxilo; el segundo, un oxígeno entre carbonos.

```smiles
CCO
```

```smiles
COC
```

La capacidad del etanol para donar enlaces de hidrógeno ayuda a explicar las
diferencias de propiedades físicas entre estos isómeros. Una fórmula molecular
no informa, por sí sola, de todas esas propiedades.

## Practica

1. Cuenta los hidrógenos del butano utilizando la valencia habitual 4 del
   carbono.
2. ¿Cambiar la orientación del dibujo del butano crea otro isómero?
3. ¿Qué información falta en una fórmula molecular para identificar estas
   parejas?

## Respuestas comentadas

1. Los carbonos terminales tienen tres H cada uno; los internos, dos:
   $3+2+2+3=10$.
2. No. Girar el dibujo sin cambiar los enlaces conserva la conectividad.
3. Los enlaces entre los átomos; en otros casos también se necesita la
   configuración espacial.
