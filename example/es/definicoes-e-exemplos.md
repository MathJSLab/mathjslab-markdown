# Definiciones y ejemplos: norma de un vector

**Extensiones:** `didactic`, `cross-references`, `mathjax`.

## Ideas principales

Una definición fija el significado; un ejemplo muestra cómo usarla.

La {@ref norma} y el ejemplo siguiente distinguen un vector de su longitud.

::: definition Norma euclídea {#norma}

Para $v=(x,y)$, definimos $\|v\|=\sqrt{x^2+y^2}$.

:::

::: example Vector (3,4)

$\|(3,4)\|=\sqrt{9+16}=5$.

:::

## Práctica

Calcule la norma de (-3,4). ¿El signo negativo hace negativa la longitud?

## Respuesta comentada

La norma vale 5; los cuadrados de las componentes son no negativos.
