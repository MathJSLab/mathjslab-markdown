# Amoníaco: geometría piramidal

**Extensiones:** `molecule-3d`, `smiles`, `mathjax`.

## Ideas principales

El amoníaco $\ce{NH3}$ tiene tres enlaces N–H y un par de electrones no
enlazante. Las coordenadas XYZ son un modelo ilustrativo de pirámide trigonal,
no una medición. SMILES por sí solo no determina la geometría espacial.

```smiles
N
```

```xyz
4
Modelo ilustrativo de amoníaco
N 0.000 0.000 0.300
H 0.940 0.000 -0.100
H -0.470 0.814 -0.100
H -0.470 -0.814 -0.100
```

## Práctica

¿Cuántos átomos hay en el modelo? ¿Toda la molécula es plana?

## Respuesta comentada

Hay cuatro átomos. No: el nitrógeno está fuera del plano de los tres
hidrógenos.
