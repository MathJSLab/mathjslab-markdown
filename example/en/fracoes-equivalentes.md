# Equivalent fractions and addition

**Objective:** add fractions using equal-sized units. **Extensions:** MathJax,
Mermaid.

## Key ideas

The fraction $a/b$, with $b\ne0$, compares a quantity with a division of the
unit. Multiplying numerator and denominator by the same nonzero number keeps
the value unchanged: $1/2=3/6$. Both the number and the size of the parts
change.

To add $1/2+1/3$, write both terms in sixths. We cannot simply add the
denominators because they describe different-sized parts.

$$
\frac12+\frac13=\frac36+\frac26=\frac56.
$$

```mermaid
flowchart LR
 A[Identify denominators] --> B[Choose a common unit]
 B --> C[Convert and add numerators]
 C --> D[Simplify]
```

The least common multiple gives a small common denominator, but other common
multiples also work. Simplifying the result shortens the notation without
changing the quantity. The same reasoning applies to length and time
measurements when a common unit is used.

## Practice

1. Calculate $1/4+1/6$.
2. Explain why $2/4$ and $1/2$ represent the same value.

## Answers with explanations

1. $3/12+2/12=5/12$.
2. Two quarter-sized parts make half of the unit.
