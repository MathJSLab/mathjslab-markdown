# Definitions and examples: vector norm

**Extensions:** `didactic`, `cross-references`, `mathjax`.

## Key ideas

A definition fixes meaning; an example shows how to use it. {@ref norma} and
the example below distinguish a vector from its length.

::: definition Euclidean norm {#norma}

For $v=(x,y)$, define $\|v\|=\sqrt{x^2+y^2}$.

:::

::: example Vector (3,4)

$\|(3,4)\|=\sqrt{9+16}=5$.

:::

## Practice

Find the norm of (-3,4). Does the negative sign make the length negative?

## Answer with explanation

The norm is 5; squared components are nonnegative.
