# Markdown lesson notes

This collection contains **50 teaching notes in English**, translated from
[the Brazilian Portuguese collection](../pt/README.md), covering all 14
extensions in the mathjslab-markdown catalogue. Each note includes objectives,
explanations, examples, exercises and answers with explanations. Teaching data
and geometries are embedded in the notes, except for the local CSV supplied in
[resources/temperaturas.csv](resources/temperaturas.csv).

Filenames are shared across language directories to make corresponding lessons
easy to locate. Command identifiers and CSV column names retain their original
spelling; their meaning is explained in the notes.

The new notes add mathematics, physics, chemistry, biology, geography, history,
music, geometry and computing. The second local resource,
[resources/observacoes.csv](resources/observacoes.csv), accompanies the lesson
on means and extreme values.

## How to view

Open the notes in a host using the package with the indicated extensions
enabled. An ordinary Markdown viewer may display rich blocks as source code.
Use the GFM profile for tables and task lists. Configuration details are in the
[extension catalogue](../../doc/extensions/README.md) and
[authoring guide](../../doc/authoring.md).

MathJSLab requires a host-provided executor; executable blocks depend on
execution policy. Expressions delimited by `%` present mathematical notation.
Molecules and 3D models require authorized WebGL. Audio, when available,
requires permission and a user action. Maps can work with vector features only,
without requesting external basemaps.

To resolve links between notes and the CSV, set `sourceUrl` to each document's
actual address. The reading-data note demonstrates relative links and
navigation by heading identifiers; these extensions are useful throughout the
collection.
